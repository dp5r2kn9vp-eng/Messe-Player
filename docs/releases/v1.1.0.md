# Messe-Player 1.1.0

Update mit Animationen für Texte, Bilder und Logos auf dem Ausgang.

## Neu

- Texte, Bilder und Logos lassen sich animieren: Sie erscheinen nach Wahl (z. B. einblenden, von unten, Zoom), können verzögert starten, blinken oder pulsieren und optional wieder ausblenden. Die Animation startet mit jedem Durchlauf neu.
- Im Editor legt „Bild aus Datei …“ ein Bild direkt als Ebene an; das Bild wird dabei auch in die Bibliothek übernommen.

## Animation einstellen

| Einstellung | Möglichkeiten |
| --- | --- |
| Erscheinen | Sofort, Einblenden, Von unten, Von oben, Von links, Von rechts, Zoom, Schreibmaschine (nur für Text) |
| Verzögerung | Wartezeit, bis die Ebene erscheint |
| Dauer | Wie lange das Erscheinen dauert |
| Effekt | Blinken oder Pulsieren, jeweils mit Tempo |
| Wieder ausblenden | Nach x Sekunden |

Im Editor zeigt „Animation ansehen“ unter der Vorschau den Ablauf so, wie er auf dem Fernseher erscheint. „Bearbeiten“ stoppt ihn.

## Installation

Wie bei 1.0.0: Zip entpacken, alte App in Programme ersetzen, beim ersten Start Rechtsklick → Öffnen.
