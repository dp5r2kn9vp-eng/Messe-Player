# Messe-Player 1.0.1

Kleines Update für die Bedienung von Gruppen auf der Messe.

## Neu

- Mehrere Einträge einer Gruppe lassen sich mit ⌘- oder ⇧-Klick gleichzeitig auswählen.
- Im Gruppenkopf kann die Standdauer für alle ausgewählten Bilder auf einmal gesetzt werden. Eine Dauer-Änderung direkt an einem der ausgewählten Einträge gilt ebenfalls für alle.

## Installation

Wie bei 1.0.0: Zip entpacken, alte App in Programme ersetzen, beim ersten Start Rechtsklick → Öffnen.
