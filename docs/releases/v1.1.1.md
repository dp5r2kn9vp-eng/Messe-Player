# Messe-Player 1.1.1

Kleines Update zum Stoppen der Wiedergabe: Esc und ⌘. verhalten sich bei externem Bildschirm unterschiedlich.

## Geändert

| Situation | Esc | ⌘. (Cmd+Punkt) |
|---|---|---|
| Nur MacBook-Bildschirm | beendet | beendet |
| Externer Bildschirm angeschlossen | ohne Wirkung | beendet (Notfall) |

Den Notfall-Stopp gibt es auch im Menü „Wiedergabe → Wiedergabe beenden“.

## Installation

Wie bei 1.0.0: Zip entpacken, alte App in Programme ersetzen, beim ersten Start Rechtsklick → Öffnen.
