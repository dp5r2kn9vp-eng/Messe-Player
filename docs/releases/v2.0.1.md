# CueView 2.0.1

Wartungs-Update ohne Änderungen an der Bedienung.

## Geändert

- Die App trägt jetzt intern die Commit-ID ihres Build-Stands. So lässt sich bei jedem ausgelieferten Paket eindeutig nachprüfen, aus welchem Stand es gebaut wurde.

## Installation

Wie bisher: Zip entpacken, alte App in Programme ersetzen, beim ersten Start Rechtsklick → Öffnen.
