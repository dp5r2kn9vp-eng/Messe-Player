# CueView 1.2.0

Der Messe-Player heißt jetzt CueView und hat ein eigenes Logo. Neu sind Hilfe, Info und ein Willkommensfenster.

## Neu

- Name und Logo: eigenes App-Icon und Wortmarke in der Kopfzeile.
- Über CueView: Version, Copyright und Website.
- Hilfe mit ⌘?: Handbuch mit sieben Themen, von „Erste Schritte“ bis „Checkliste Messe-Aufbau“.
- Tastenkürzel mit ⌘/ im Hilfe-Menü.
- Willkommensfenster beim Start ohne offenes Projekt: Neues Projekt, Öffnen, Zuletzt geöffnet, Beispielprojekt, Hilfe.
- Beispielprojekt „CueView Beispiel“ zum Ausprobieren, liegt in Dokumente.

## Wichtig beim Update

Die App heißt jetzt CueView.app. Bitte die alte MessePlayer.app im Ordner Programme löschen.
Projekte, Einstellungen und das zuletzt geöffnete Projekt bleiben erhalten.

## Installation

Zip entpacken, CueView.app in Programme ziehen, beim ersten Start Rechtsklick → Öffnen.
