# CueView 2.1.2

Stand: 2026-11-14

## Behoben

- CueView startet jetzt wirklich mit dem Startbildschirm. Das letzte Projekt öffnet sich nur noch nach einem Absturz oder Stromausfall automatisch.
- Die Restzeit in der Cue-Liste steht kompakt als `0:42` in einer Zeile. Die Zeile springt während der Wiedergabe nicht mehr.

## Geändert

- „Black“ je Ausgang gibt es nur noch, wenn der Ausgang auf einem externen Bildschirm läuft (z. B. Fernseher). Auf dem eigenen MacBook-Bildschirm und in der Vorschau entfällt die Schaltfläche. „Black alle“ (B) bleibt wie gewohnt.

## Installation

Wie bisher: Zip entpacken, alte App in Programme ersetzen, beim ersten Start Rechtsklick → Öffnen.
