# CueView 2.1.0

Stand: 2026-11-14

Diese Version ändert den Start der App und fragt beim Beenden nach.

## Geändert

- CueView startet immer mit dem Willkommensfenster, nicht mehr automatisch mit dem letzten Projekt. Das letzte Projekt lässt sich dort mit „… fortsetzen“ (Eingabetaste) öffnen.
- Das letzte Projekt samt Ausgabezustand öffnet sich nur noch automatisch nach einem Absturz oder Stromausfall.

## Hinzugefügt

- Willkommensfenster: Änderungsdatum bei „Zuletzt geöffnet“, fehlende Projekte sind als „nicht gefunden“ markiert, außerdem werden angeschlossene Bildschirme und die wichtigsten Tasten angezeigt.
- Nachfrage beim Beenden mit ⌘Q. Läuft gerade etwas auf einem Ausgang, weist der Dialog deutlich darauf hin. Beim Abmelden oder Ausschalten des Macs erscheint keine Nachfrage.

## Installation

Wie bisher: Zip entpacken, alte App in Programme ersetzen, beim ersten Start Rechtsklick → Öffnen.
